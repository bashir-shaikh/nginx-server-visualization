# 🌐 Nginx-Verse – Static Website Deployment Using GitHub Pages

## 📌 Project Overview

Nginx-Verse is a beginner-friendly DevOps project that demonstrates how to create, upload, and deploy a static website using **GitHub Pages**.

The project covers the fundamentals of HTML, CSS, Git, GitHub repositories, and static website hosting. It demonstrates how a website can be published publicly over HTTPS without managing or configuring a physical server.

## 🎯 Project Objectives

- Understand Git and GitHub fundamentals.
- Create a static website using HTML and CSS.
- Upload project files to a GitHub repository.
- Configure GitHub Pages for website deployment.
- Host a website publicly using HTTPS.
- Understand the deployment and update process.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- HTTPS

## ⚙️ Project Architecture

Local Project Files → GitHub Repository → GitHub Pages → Public Website

## 🚀 Deployment Process

1. Created a GitHub repository.
2. Created the project directory and required files.
3. Developed the website using HTML and CSS.
4. Uploaded the project files to GitHub.
5. Configured GitHub Pages.
6. Selected the `main` branch and root folder.
7. Enabled HTTPS.
8. Verified the deployed website through its public URL.
